# Document Search

## Overview
A simple AI-style document search system for finding relevant text documents.

---

## Features
- Load text documents
- Search documents using keywords
- Return matching file names

---

## Files
- `load_documents.py` → loads text documents
- `search.py` → performs keyword search

---

## Folder Structure

```text
documents/
├── file1.txt
├── file2.txt
```

---

## Usage

```bash
python search.py
```

---

## Example Query

```text
machine learning
```

---

## Example Output

```text
Matching Documents:
notes.txt
ai.txt
```

- Text search systems
